# Paper Record: P205

- **Paper ID:** P205
- **Title:** The Anatomy of a Large-Scale Hypertextual Web Search Engine
- **Authors:** Sergey Brin, Lawrence Page
- **Year:** 1998
- **Conference:** Seventh International World Wide Web Conference (WWW 1998)
- **Domain:** Link Analysis, Citation Graphs, PageRank

## Abstract
In this paper, we present Google, a prototype of a large-scale search engine which makes heavy use of the structure present in hypertext. Google is designed to crawl and index the Web efficiently and produce much more satisfying search results than existing systems. To handle link structure, we introduce PageRank, an algorithm for calculating the importance of web pages by treating hyperlinks as directed citations from one document to another.
